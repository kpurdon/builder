# Datadog guidance

Use upstream `dd-pup` and domain guides for tooling; report missing prerequisites with the [setup path](https://github.com/DataDog/pup#agent-skills).

Prefer shareable notebooks with executable queries and source links for related signals. When gathering or presenting findings, use [evidence guidance](../../../references/quality.md). When creating or updating Datadog artifacts, use [artifact checks](../../execute/references/operations.md#operational-artifacts).
