# Session handoffs

- Use the [brief](../../../templates/handoff.md) for requested handoffs, giving each independent delivery one owner and an observable finish line.
- Launch an execution session only on explicit request and follow the selected integration’s membership and launch rules.
- Use Dispatcher’s transfer procedure only when moving a registered session to another initiative.
- When authorized, retire a session once its work is complete, canceled, or explicitly transferred and no active work depends on it.

## Delivery state and blockers

Use linked delivery evidence to resolve dependencies and bring blockers requiring a decision or approval directly to the user.
