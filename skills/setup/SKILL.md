# setup

Follow the [working agreement](../../references/working-agreement.md).

- Verify installed skills and the current [host](../../references/codex.md), [worker](references/agents.md), and [Datadog](../investigate/references/datadog.md) capabilities needed for the task.
- Verify the selected session integration’s identity, membership, launch, message, and retirement capabilities without launching or adopting sessions for inspection.
- Change agent installations only on request and report readiness separately from observed execution.
