# design

Follow the [working agreement](../../references/working-agreement.md).

- Investigate what could change the recommendation and compare viable approaches.
- Resolve routine choices and bring consequential decisions to the user before treating them as settled.
- When asked for a plan, give testable outcomes, dependencies, and rollout order using [PR delivery](../execute/references/pr-delivery.md) and [operational procedures](../execute/references/operations.md).
